# 解除佔用

「檔案正在被另一個程式使用，無法刪除」——遇到這個提示時，這個頁面就是你的救星。「解除佔用」自 v0.1.1 起也是**獨立的導覽分類和獨立頁面**。

## 它能幹什麼

### 尋找佔用程序

指定一個被佔用的檔案或目錄，幫你查出到底是哪個程序在佔用它。

### 關閉程式釋放佔用

找到佔用程序後，可以將其關閉來釋放佔用。關閉之後，剛才刪不掉的檔案就能正常刪除了。

**注意**：系統核心程序在內建黑名單裡，**禁止強制結束**，不用擔心手滑把系統搞崩。

### 開機延遲刪除

有些檔案實在頑固，當前怎麼都刪不掉。這個功能會安排它在**下次開機時刪除**——系統啟動早期檔案還沒被佔用，刪除就能成功。底層用的是 Windows 原生的檔案操作能力（如 MoveFileEx 的延遲操作機制）。

## 和解除安裝程式的聯動

解除安裝軟體時遇到「檔案被佔用」，可以直接轉到這個頁面處理佔用，再回去繼續清理。兩個頁面是設計好聯動的。

## 使用建議

1. 先在佔用頁面查清楚是**誰**在佔用，別上來就關程序——萬一是你沒儲存的文件呢；
2. 確認程序可以關，再執行關閉；
3. 實在刪不掉的，用開機延遲刪除兜底；
4. v0.1.2 修復了小視窗下佔用程序列表高度塌陷、滾輪被吞的問題，現在列表可以隨整頁正常捲動，版本舊的建議升級。

<VTDocTip>
底層實作只調用微軟原生 Win32 API（RestartManager、MoveFileEx 等），不依賴第三方驅動或魔法，代碼開源可查。
</VTDocTip>
