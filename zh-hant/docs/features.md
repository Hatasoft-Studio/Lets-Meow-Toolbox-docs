# 功能分區

程式裡的功能不是一股腦堆在一起的，而是按「風險高低、用途不同」分成了幾個區。這一頁給你一張總覽圖，每個區的詳細用法點對應連結進去看。

## 一張表看懂所有分區

| 分區 | 定位 | 裡面有什麼 |
| --- | --- | --- |
| 🟢 新手區 | 預設不啟用、無需風險確認 | Win11 經典右鍵選單、工作列/檔案總管微調、關閉廣告/遙測/通知推薦、安全 UWP 解除安裝（白名單）、電源/索引/自動播放/縮圖優化、一鍵還原 |
| 🟡 進階區 | 勾選風險提示後解鎖 | Windows 更新暫停期限/停用、一鍵還原 |
| 📦 解除安裝程式 | 獨立頁面 | Win32 軟體批次解除安裝、殘留掃描與清理、匯出清理報告，與「解除佔用」聯動 |
| 🔓 解除佔用 | 獨立頁面 | 尋找佔用程序、關閉程式釋放佔用、開機延遲刪除 |
| 🔴 高危外掛區 | 外置 DLL 外掛 | 關閉 Defender / 關閉防火牆 / 移除 Edge·WebView2。主程式本體不含任何高危代碼，僅動態載入 `plugins` 目錄下的外掛 DLL |
| ⚙️ 設定 | 獨立頁面 | 語言包選擇與安裝、檢查更新、外觀、配置預設匯入匯出、記錄目錄、一鍵初始化全部內容、關於與更新記錄 |
| 💖 特別鳴謝 | 獨立頁面 | 本項目集成的其他開源項目 |

## 為什麼這麼分

- **新手區**裡的操作都比較溫和，所以不需要你勾選什麼風險確認，適合剛裝完系統的朋友；
- **進階區**裡的操作影響更大（比如動 Windows 更新），所以要先勾選風險提示才會解鎖；
- **解除安裝程式**和**解除佔用**自 v0.1.1 起從原來的分區裡拆了出來，各自成為獨立的導覽分類和獨立頁面，用起來更順手；
- **高危外掛區**最特殊：這些功能（關 Defender、刪 Edge 之類）風險高，所以作者把它們全部做成了**外置外掛**，主程式本身一行高危代碼都沒有。你不用外掛，程式就完全不含這些功能。

## v0.2.0 新增：多語言與軟體更新

這兩個能力都放在「設定」頁裡，不單獨佔分區：

- **語言 / Language**：簡體中文內嵌在程式本體；繁體中文、日語、英語等以 `.meowlang` 語言包的形式放在 `lang` 目錄，可以一鍵選擇、安裝，載入後自動重新啟動生效；
- **軟體更新**：設定頁可以「檢查更新」，有新版本會展示版本號與更新內容；如果當前版本已經被官方標記為停止支援，啟動時會強制要求更新。

詳細操作與語言包格式見[設定與關於](/zh-hant/docs/settings.html)。

## 所有分區都遵守的安全底線

- 所有修改、刪除、清理操作**均需使用者手動確認**，沒有任何自動執行邏輯；
- 殘留、佔用項**預設不勾選**，想清理得你自己勾上；
- 內建黑名單：`C:\Windows`、`System32`、`WinSxS` 等系統核心目錄與系統核心程序禁止強制結束；
- 程式不加殼、不混淆，底層只調用微軟原生 Win32 API（RestartManager、MoveFileEx、Registry 等），代碼全部開源可查。
