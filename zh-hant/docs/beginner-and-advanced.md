# 新手區與進階區

這兩個區是程式裡做「系統調優」的主力。新手區溫和、不用確認；進階區動作大、要先勾選風險提示。這一頁把每個功能用白話講一遍。

## 🟢 新手區

定位：**預設不啟用、無需風險確認**。裡面的功能都是「改了更好用，改錯了也能還原」的類型。

### Win11 經典右鍵選單

Win11 的右鍵選單藏了一層「顯示更多選項」，很多人覺得反人類。這個開關幫你切回 Win10 風格的經典右鍵選單，點一下右鍵所有選項直接出來。

### 工作列 / 檔案總管微調

對工作列和檔案總管裡一些礙眼的小細節做調整，讓日常操作更順手。

### 關閉廣告 / 遙測 / 通知推薦

Windows 裡不時冒出來的推薦內容、廣告位和遙測上報，這個功能按公開的登錄口徑把它們關掉。鍵位口徑參考了開源項目 Win11Debloat 的公開清單。

### 安全 UWP 解除安裝（白名單）

解除安裝 Win11 預裝的那些用不上的 UWP 應用程式。為了防誤刪，程式內建了一份**白名單**：系統關鍵元件不在可解除安裝範圍內，不用擔心把系統卸壞。白名單同樣參考了 Win11Debloat 的公開清單。

### 電源 / 索引 / 自動播放 / 縮圖優化

一組針對常見效能與體驗細節的一鍵優化項，包括電源方案、搜尋索引、自動播放和縮圖相關設定。

### 一鍵還原

在新手區裡改過的東西，可以用一鍵還原恢復回去。改之前不用慌，後悔藥是現成的。

## 🟡 進階區

定位：**勾選風險提示後解鎖**。裡面的功能對系統影響更大，所以程式會先讓你確認自己知道在幹什麼。

### Windows 更新暫停期限 / 停用

Windows 更新有時候來得不是時候。這個功能可以調整更新的暫停期限，或直接將其停用。登錄 / 命令口徑參考了 Sophia Script 的公開腳本。

### 一鍵還原

和新手區一樣，進階區的改動也支援一鍵還原。

<VTDocWarning>
進階區涉及 Windows 更新策略，改動前請確認你理解後果。所有操作仍需手動確認後才執行，但「確認了再執行」不等於「執行了沒影響」，請按需使用。
</VTDocWarning>

## 小提示

- 每個開關旁邊都有白話說明，不確定的先看說明再動手；
- 所有操作都會被記錄到記錄檔（INFO / WARN / ERROR），出了問題可以翻記錄對照；
- 改完不滿意，優先用對應分區的「一鍵還原」。
