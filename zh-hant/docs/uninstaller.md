# 解除安裝程式

「解除安裝程式」自 v0.1.1 起是一個**獨立的導覽分類和獨立頁面**，專門對付「軟體裝了一堆、解除安裝不乾淨」的問題。

## 它能幹什麼

### Win32 軟體批次解除安裝

列出系統裡已安裝的 Win32 軟體，可以一次勾選多個批次解除安裝，不用一個個進控制台慢慢點。

### 殘留掃描與清理

軟體解除安裝之後，往往還會留下一堆登錄機碼和資料夾殘留。這個功能會掃描這些殘留，讓你勾選後清理掉。

**注意**：殘留項**預設是不勾選的**。程式的態度是「寧可少刪，不可誤刪」，你要清理哪些，得自己看清楚了再勾。

### 匯出清理報告

解除安裝和清理的過程可以匯出成報告，方便你存檔或者排查問題。

### 與「解除佔用」聯動

解除安裝時最怕「檔案被佔用刪不掉」。這個頁面和[解除佔用](/zh-hant/docs/unlock.html)是聯動的，遇到佔用問題可以直接借助解除佔用頁處理。

## 設計上參考了誰

解除安裝與殘留掃描模組的設計思路，參考了開源項目 **Bulk Crap Uninstaller（BCU，GPL-3.0）** 的解除安裝登錄讀取與殘留偵測方案——但注意是**獨立實作**，不是照搬代碼。

## 使用建議

<VTDocSteps>
  <VTDocStep title="先勾選要解除安裝的軟體">
    在列表裡勾選目標軟體。看準了再勾，批次解除安裝一旦開始就是按順序執行。
  </VTDocStep>
  <VTDocStep title="執行解除安裝並逐項確認">
    解除安裝與後續的清理操作都會經過你的手動確認，不會自動動手。
  </VTDocStep>
  <VTDocStep title="掃描殘留，按需勾選">
    解除安裝完成後掃描殘留。殘留預設不勾選，確認無誤後再選擇清理。
  </VTDocStep>
  <VTDocStep title="匯出報告存檔">
    需要的話匯出清理報告，方便日後回溯。
  </VTDocStep>
</VTDocSteps>

<VTDocNote>
系統核心目錄（C:\Windows、System32、WinSxS）在程式的內建黑名單裡，不會被當成殘留誤刪。
</VTDocNote>
