# 高危外掛區

這是整個程式裡最需要「看清楚再動手」的地方。先說結論：**主程式本體不含任何高危代碼**，所有高危功能都是外置外掛，你不放外掛，這裡就是空的。

## 為什麼高危功能要做成外掛

作者的設計原則很明確：高危操作（關閉防毒、拆系統元件這類）絕不能混在主程式裡。所以它們被全部拆成了**外置 DLL 外掛**，放在程式同級的 `plugins` 目錄裡，由主程式動態載入。

這樣做的好處：

- 主程式（`LetsMeowToolbox.exe`）可以隨便審查，裡面一行高危代碼都沒有；
- 你不想要高危功能，不放外掛就行，互不打擾；
- 外掛刪掉即移除，乾淨俐落。

## 官方高危外掛提供哪些操作

儲存庫自帶的官方高危外掛（`LetsMeowToolbox.Plugins.HighRisk`）包含三個操作：

| 操作 | 說明 |
| --- | --- |
| 關閉 Defender | 關閉 Windows Defender 防護 |
| 關閉防火牆 | 關閉 Windows 防火牆 |
| 移除 Edge · WebView2 | 移除 Edge 瀏覽器與 WebView2 元件 |

## 怎麼啟用

發布包裡自帶 `plugins` 目錄。官方高危外掛的 DLL（`LetsMeowToolbox.Plugins.HighRisk.dll`）在官方發布流程中會被複製到該目錄；如果你手裡的版本 `plugins` 目錄是空的，把高危外掛 DLL 放進去，重新打開程式即可載入。

## 使用前必須知道的事

<VTDocWarning>
高危操作之所以叫高危，是因為它們真的會影響系統安全與穩定性：

- 關閉 Defender / 防火牆會讓電腦失去防護；
- 移除 Edge / WebView2 可能影響依賴 WebView2 的程式。

每個操作在啟用前都會向你展示**風險提示文案並要求二次確認**，請真的讀完再點確認。外掛契約明確禁止任何「自動執行、自動確認、無提示」的邏輯，所以你不會在不知情的情況下執行任何高危操作。
</VTDocWarning>

- 所有高危操作都需要**手動確認**後才執行；
- 需要管理員權限的操作會額外要求管理員權限；
- 每個操作都提供**還原**能力，啟用後發現不對勁可以還原；
- 操作結果會寫入記錄，方便回溯。

## 想自己寫高危外掛？

程式開放了外掛契約，允許第三方開發高危外掛（風險自負）。開發文件見[高危外掛開發](/zh-hant/dev/high-risk-plugin-development.html)。
