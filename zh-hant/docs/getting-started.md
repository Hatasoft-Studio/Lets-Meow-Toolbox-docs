# 快速上手

這一頁帶你從零開始，把 Let's Meow! Toolbox 下載下來並跑起來。全程不需要任何專業知識，跟著點就行。

## 先看看你的電腦符不符合要求

- **系統**：Windows 10 或 Windows 11（只支援這兩個，Win7/8 不行）
- **架構**：64 位（x64）
- 其他沒了。是否需要提前裝執行庫，取決於你下載哪個版本，下面會說。

## 第一步：去下載頁拿安裝包

打開網站頂部的[下載](/zh-hant/download.html)。這個頁面會**自己去 GitHub 上查詢所有版本**，你不用手動找連結：

- 「更新通道」分兩種：**Release**（正式版）和 **Pre Release**（預發布版），日常用選 Release 就行；
- 「版本」下拉框裡列出了該通道下的全部版本，最新版排在最前面，也可以選更早的版本；
- 頁面會根據你的電腦，把最合適的安裝包做成大按鈕放在最顯眼的位置；
- 如果某個版本沒有提供安裝版，安裝版按鈕會自動隱藏，這是正常的。

下載線路有兩條：

1. **GitHub**：官方管道。因為 GitHub 伺服器在海外，有時候下載會很慢；
2. **EZ-Mirror 鏡像**：下載慢就切到這條線路，由 [EZ-Mirror](https://mirror.hatasoft365.top/) 提供加速。

<VTDocNote>
Pre Release（預發布）版本**只能從 GitHub 下載**，鏡像站不同步預發布版本，所以選了 Pre Release 通道時看不到線路切換。
</VTDocNote>

## 第二步：搞清楚兩個「免安裝版」的區別

每個版本一般都有兩個 zip，檔名很長，但區別其實很簡單：

| 檔名裡的關鍵詞 | 頁面上叫 | 體積 | 要不要先裝 .NET | 一句話解釋 |
| --- | --- | --- | --- | --- |
| `framework-dependent` | 免安裝精簡版 | 小，約 10~20 MB | 要 | 本體小，但電腦裡得先裝好 .NET 8 桌面執行階段 |
| `self-contained` | 免安裝完整版 | 大，約 90~110 MB | 不要 | 把執行庫一起打包進來了，什麼都不用裝 |

不知道選哪個？**怕麻煩就選大的（免安裝完整版）**，雙擊就能用。

有的版本還會多一個 `.exe` 安裝包（檔名帶 `installer-version`），它本質上就是「免安裝完整版」的安裝包，喜歡走安裝嚮導的可以選它。注意**不是每個版本都有安裝包**，以下載頁實際列出的為準。

## 第三步：執行

**免安裝版（zip）**：

1. 把 zip 解壓縮到任意目錄（比如 `D:\Tools\LetsMeowToolbox`）；
2. 雙擊裡面的 `LetsMeowToolbox.exe`，完事。

**安裝包（exe）**：雙擊後按嚮導一路下一步即可。

<VTDocTip>
解壓縮後你會看到一個 `plugins` 資料夾，那是放高危外掛的地方。主程式本身不含任何高危代碼，高危功能全部來自這個資料夾裡的外置外掛，詳見[高危外掛區](/zh-hant/docs/high-risk-zone.html)。
</VTDocTip>

## 如果雙擊沒反應怎麼辦

十有八九是你下了「免安裝精簡版」但電腦裡沒裝執行庫。兩個解決辦法任選：

1. 安裝 [.NET 8 桌面執行階段](https://dotnet.microsoft.com/download/dotnet/8.0)（選「.NET Desktop Runtime 8.x」），裝完再打開程式；
2. 或者直接換「免安裝完整版」，自帶執行庫。

更多情況見[常見問題](/zh-hant/docs/faq.html)。

## 順便說一句

程式的所有修改、刪除、清理操作**都會先問你一遍才執行**，不會偷偷自動動手；殘留和佔用項預設也是不勾選的，可以放心點點看。
