# 設定與關於

設定頁管的是程式自己的「家務事」：語言、軟體更新、外觀、配置、記錄和版本資訊。v0.2.0 起設定頁頂部新增了**語言**與**軟體更新**兩張卡片，這一頁按卡片順序逐個講清楚。

## 語言 / Language

v0.2.0 開始，程式支援**外置語言包**。規則很簡單：

- **簡體中文是源語言**，直接內嵌在程式本體裡，就算一個語言包都沒裝，介面也不會變成外文；
- 其他語言（繁體中文、日語、英語等）以 `.meowlang` 檔案的形式放在程式目錄下的 `lang` 資料夾裡，啟動時自動掃描；
- 官方語言包（繁體中文、日語、英語）隨程式一起發布，解壓縮後就在 `lang` 目錄裡，不用另外下載。

語言卡片上會顯示「當前語言：xxx」，下面有兩個按鈕。

### 選擇語言

點「選擇語言」會打開獨立的「語言管理」視窗：

- 視窗頂部顯示語言包目錄的完整路徑；
- 列表會列出 `lang` 目錄下的全部語言包，順序是：內嵌簡體中文 → 官方語言包 → 第三方語言包，再按名稱排序；
- 選中某一項後可以查看它的詳情（包名、製作者、版本、適用版本、簡介、作者網站等）；
- 點「載入所選語言」後，程式會先檢查這個語言包是否適用於當前版本，通過後彈出詳情確認，確認載入會**自動重新啟動程式**生效——重新啟動是為了讓所有介面文字都重新翻譯一遍，屬於正常現象。

<VTDocTip>
語言包載入失敗時，程式會告訴你原因（例如「該語言包適用於 0.1.2，當前軟體版本為 v0.2.0」），並寫入記錄，不會靜默失敗。
</VTDocTip>

### 安裝語言包

點「安裝語言包」會打開檔案選擇對話方塊，選中一個 `.meowlang` 檔案後，按下面的流程走：

1. **讀取與校驗**：檢查 `id`、`name`、`author`、`version`、`strings` 這些必填欄位是否齊全，格式壞了會直接報錯並寫入記錄；
2. **版本相容檢查**：語言包宣告的適用版本必須符合當前程式版本，否則拒絕安裝；
3. **詳情確認**：彈窗展示包名、製作者、適用版本、安裝時間、語言類型、語言編碼、檔案大小、簡介與作者網站；官方語言包的製作者旁邊會帶一個**綠色盾牌標識**；
4. **第三方確認**：如果製作者/作者網站不是官方（`Hatasoft-Studio` + 官方站點），會再彈一次「該語言包由第三方個人製作者/社群提供，是否繼續安裝？」；
5. **進度視窗**：帶進度條地把語言包複製到 `lang` 目錄；
6. **結果提示**：成功時提示「語言包安裝成功！」，失敗時顯示失敗原因和記錄檔路徑。

安裝完成後，可以在「選擇語言」裡切換到剛裝好的語言。

### 同名語言包的更新 / 降級

如果 `lang` 目錄裡已經存在同名的語言包，安裝時會：

- 先比較版本號，告訴你這次是**更新**、**降級**還是**重新安裝**，並二次確認；
- 如果新舊語言包的**作者或作者網站不一致**，程式會直接拒絕覆蓋，並提示你手動刪除舊語言包後再裝——這是為了防止有人拿別人的語言包 ID 做覆蓋投放。

### 適用範圍怎麼寫

語言包的 `appVersion` 欄位決定它能用在哪些版本上：

| 寫法 | 含義 |
| --- | --- |
| `*` 或留空 | 所有版本都適用 |
| `>=0.2.0` | v0.2.0 及之後的版本 |
| `0.2.0 \| 0.2.1 \| 0.2.2` | 僅這幾個版本適用（v0.2.0 起支援用 `\|` 分隔多個版本號） |
| `<0.3.0` | v0.3.0 之前的版本 |

也支援 `>=`、`<=`、`>`、`<`、`=` 與 `*`，多個條件可以用空格或逗號組合（需要同時滿足）。看不懂也沒關係——裝不上時程式會把原因寫出來。

## 軟體更新

v0.2.0 新增了「軟體更新」卡片，裡面就一個「檢查更新」按鈕。

點一下之後，程式會向官方更新介面（`https://api.lets-meow-toolbox.hatasoft365.top/`）請求最新版本號、下載位址、更新說明與「已停止支援的版本列表」，然後：

- **有新版本**：彈窗展示當前版本、最新版本、版本號、更新內容，以及「前往官網取得新版本」按鈕；不想馬上更新可以點「稍後再說」；
- **已是最新**：按鈕旁邊直接提示「當前已是最新版本（v0.2.0）」；
- **網路失敗或介面異常**：提示「檢查更新失敗：原因」，不影響程式繼續使用，過一會兒再試即可。

<VTDocWarning>
**停止支援版本檢測：** 如果介面返回的「不受支援版本列表」裡包含你正在使用的版本，程式在**啟動時**就會彈出強制更新提示，標題是「此版本已停止支援」，只能選擇「前往官網取得新版本」或「結束程式」——更新前無法繼續使用。這是為了讓舊版本徹底退場，避免已知問題繼續被使用。
</VTDocWarning>

## 外觀

程式自帶多套主題畫筆，包括淺色主題與**二次元模式**（沒錯，這是一個二次元現代化 UI 的工具箱，桌布與配色都是配套的）。

- 非 Win11 系統上，視窗背景可能會自動回退為純色，這是預期行為，不影響使用；
- v0.1.1 優化過二次元模式下開關與按鈕的顏色、文字可讀性，老版本覺得字淡的建議升級。

## 配置預設匯入 / 匯出

你在程式裡做的功能設定，可以匯出成 `.meowpreset` 預設檔儲存；換電腦或重裝系統後，再匯入回來，不用重新一個個勾。

## 記錄目錄

程式內建全域記錄（v0.1.1 起改為全域記錄）：你的全部設定操作、執行結果與時間都會按 INFO / WARN / ERROR 級別記下來，不再是空檔案。

- 記錄位置：`%LocalAppData%\LetsMeowToolbox\logs\meow-日期.log`
- 檔案總管位址欄貼上 `%LocalAppData%\LetsMeowToolbox\logs` 按 Enter 即可打開。
- 語言包安裝失敗、更新檢查失敗也會寫進這份記錄。

## 一鍵初始化全部內容

v0.1.1 新增的「後悔藥總開關」，一鍵完成三件事：

1. 還原全部功能設定到預設狀態；
2. 重設外觀設定；
3. 清空配置預設。

想把程式恢復到「剛裝好」的狀態，用這個就行。

<VTDocNote>
一鍵初始化**不會**刪除你安裝的語言包，語言包只存在於 `lang` 目錄裡。想徹底移除某個語言，直接到 `lang` 目錄刪掉對應的 `.meowlang` 檔案即可。
</VTDocNote>

## 關於與更新記錄

關於頁可以看到：

- **當前版本號**（v0.1.1 起引入版本號體系：主版本號.次版本號.修訂號，當前為 v0.2.0）；
- **「查看更新記錄」按鈕**：在程式視窗內直接看每個版本的更新內容；
- **GitHub 儲存庫資訊與「前往 GitHub 儲存庫」按鈕**：一鍵打開官方儲存庫 <https://github.com/Hatasoft-Studio/Lets-Meow-Toolbox>。
