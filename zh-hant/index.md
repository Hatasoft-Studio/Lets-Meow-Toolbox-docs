<VTDocSteps>
  <VTDocStep title="選擇版本">
    打開下載頁，頁面會自動從 GitHub 拉取最新版本，並按你的系統架構推薦安裝包。

  <VTDocStep title="下載安裝包">

  <VTDocStep title="運行">
    安裝版雙擊安裝即可；免安裝版解壓縮後直接執行可執行檔。

</VTDocSteps>
