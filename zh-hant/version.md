# 更新記錄

版本號體系自 v0.1.1 起執行：**主版本號.次版本號.修訂號**

- 主版本號：重大架構調整 / 破壞性變更時 +1（0.x 階段指整體重構）
- 次版本號：新增功能時 +1
- 修訂號：修復缺陷 / 優化時 +1

以下記錄按版本倒序，最新在上。完整代碼變更見各版本的 **Full Changelog** 連結。

## v0.2.0 · 2026-11-06

- 【新增】多語言支援：新增外置語言包機制（`.meowlang`，內容為 JSON 文字），啟動時自動掃描程式目錄下的 `lang` 資料夾。
- 【新增】簡體中文作為源語言直接內嵌於程式本體，無需安裝語言包即可使用。
- 【新增】官方語言包：繁體中文、日語、英語，隨程式發布在 `lang` 資料夾內。
- 【新增】設定頁新增「選擇語言」按鈕：獨立視窗列出 `lang` 目錄下的全部語言包，可查看詳情並載入所選語言（載入後自動重新啟動生效）。
- 【新增】設定頁新增「安裝語言包」按鈕：選擇 `.meowlang` 檔案後展示包名、製作者（官方語言包帶綠色盾牌標識）、適用版本、安裝時間、語言類型、語言編碼、檔案大小、簡介與作者網站。
- 【新增】安裝流程：帶進度條的安裝視窗，成功提示「語言包安裝成功！」，失敗時顯示原因與記錄路徑；第三方語言包需二次確認。
- 【新增】同名語言包更新/降級：自動比較版本號並二次確認；若作者或作者網站不一致則拒絕覆蓋，需手動刪除舊語言包。
- 【新增】語言包適用版本支援用 `|` 分隔多個版本號（如 `0.2.0 | 0.2.1 | 0.2.2`）。
- 【新增】設定頁新增「檢查更新」：向官方更新介面請求最新版本號，與當前版本自動比較；有新版本時展示版本號、更新內容與「前往官網取得新版本」按鈕。
- 【新增】停止支援版本檢測：更新介面返回的不受支援版本列表中包含當前版本時，啟動即彈出強制更新提示，更新前無法繼續使用本程式。
- 【修復】語言管理視窗列表項的語言包名稱不顯示、選中後無高亮效果的問題。

**Full Changelog**：<https://github.com/Hatasoft-Studio/Lets-Meow-Toolbox/compare/v0.1.2...v0.2.0>

<VTDocNote>
官方語言包（繁體中文、日語、英語）同時也以獨立版本 `v1.1.0-lang` 發布，方便只想更新語言包的使用者單獨下載 `.meowlang` 檔案。使用文件見[設定與關於](/zh-hant/docs/settings.html)，語言包格式見[語言包開發](/zh-hant/dev/language-pack-development.html)。

## v0.1.2 · 2026-10-24

- 【新增】所有頁面加入網頁風格的右側捲軸：內容超出視窗時自動出現，可上下拖動滑塊、點擊軌道翻頁，滑塊懸停/拖動時變粉色，圓角 Win11 樣式。
- 【修復】解除佔用頁佔用程序列表在小視窗下高度塌陷、滾輪被內部列表吞掉的問題，現在可隨整頁正常捲動。

## v0.1.1 · 2026-10-24

- 【修復】記錄系統：記錄改為全域記錄，記錄使用者全部設定操作、執行結果與時間（INFO/WARN/ERROR），不再為空檔案。
- 【新增】設定頁新增「一鍵初始化全部內容」：還原全部功能設定到預設狀態、重設外觀設定、清空配置預設。
- 【新增】版本號體系：自此版起為 v0.1.1，關於頁顯示當前版本；新增「查看更新記錄」按鈕（本視窗）。
- 【新增】特別鳴謝：每個開源項目新增「造訪」按鈕，一鍵打開該項目主頁/GitHub 儲存庫；新增 EZ-Mirror 條目；修復字體模糊（加大字號、加深顏色）。
- 【新增】介面重組：「解除安裝程式」與「解除佔用」從新手區/進階區拆出，各自獨立為一個導覽分類與獨立頁面。
- 【新增】關於頁新增 GitHub 儲存庫資訊與「前往 GitHub 儲存庫」一鍵按鈕。
- 【修復】二次元模式下開關與按鈕的顏色、文字可讀性優化。
