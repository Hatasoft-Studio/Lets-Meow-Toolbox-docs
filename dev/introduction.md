# 开发须知

欢迎来到开发文档。动手之前，先把几件重要的事情说清楚。

- 想自己编译一份 Let's Meow Toolbox 的人；

## 作者的话

这是一个 **Vibe-Coding 作品**。作者的原话是：如果你介意使用 Vibe-Coding 作品，请自觉离开，不要提 Issue 来骂人。程序每次发布都会经过作者亲测，基本上不会出现大问题。

作者制作这个工具的初衷，是方便自己重装系统后快速配置电脑——毕竟现在的 Win11 反人类设计太多了（尤其是右键菜单）。后来想到会有很多一样的“懒人”，就美化一下发出来了。**这个项目作者会一直维护下去。**

另外，作者自认不是什么有才之人，如果有大佬路过后想“救”一下这个项目，那就太好了。
