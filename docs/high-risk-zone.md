# 高危插件区

这是整个程序里最需要“看清楚再动手”的地方。先说结论：**主程序本体不含任何高危代码**，所有高危功能都是外置插件，你不放插件，这里就是空的。

## 为什么高危功能要做成插件

作者的设计原则很明确：高危操作（关闭杀毒、拆系统组件这类）绝不能混在主程序里。所以它们被全部拆成了**外置 DLL 插件**，放在程序同级的 `plugins` 目录里，由主程序动态加载。

这样做的好处：

- 主程序（`LetsMeowToolbox.exe`）可以随便审查，里面一行高危代码都没有；
- 你不想要高危功能，不放插件就行，互不打扰；
- 插件删掉即移除，干净利落。

## 官方高危插件提供哪些操作

仓库自带的官方高危插件（`LetsMeowToolbox.Plugins.HighRisk`）包含三个操作：

| 操作 | 说明 |
| --- | --- |
| 关闭 Defender | 关闭 Windows Defender 防护 |
| 关闭防火墙 | 关闭 Windows 防火墙 |
| 移除 Edge · WebView2 | 移除 Edge 浏览器与 WebView2 组件 |

## 怎么启用

发布包里自带 `plugins` 目录。官方高危插件的 DLL（`LetsMeowToolbox.Plugins.HighRisk.dll`）在官方发布流程中会被复制到该目录；如果你手里的版本 `plugins` 目录是空的，把高危插件 DLL 放进去，重新打开程序即可加载。

## 使用前必须知道的事

<VTDocWarning>
高危操作之所以叫高危，是因为它们真的会影响系统安全与稳定性：

- 关闭 Defender / 防火墙会让电脑失去防护；
- 移除 Edge / WebView2 可能影响依赖 WebView2 的程序。

每个操作在启用前都会向你展示**风险提示文案并要求二次确认**，请真的读完再点确认。插件契约明确禁止任何“自动执行、自动确认、无提示”的逻辑，所以你不会在不知情的情况下执行任何高危操作。
</VTDocWarning>

- 所有高危操作都需要**手动确认**后才执行；
- 需要管理员权限的操作会额外要求管理员权限；
- 每个操作都提供**还原**能力，启用后发现不对劲可以还原；
- 操作结果会写入日志，方便回溯。

## 想自己写高危插件？

程序开放了插件契约，允许第三方开发高危插件（风险自担）。开发文档见[高危插件开发](/dev/high-risk-plugin-development.html)。
