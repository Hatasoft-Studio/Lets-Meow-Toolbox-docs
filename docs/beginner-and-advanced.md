# 新手区与高级区

这两个区是程序里做“系统调优”的主力。新手区温和、不用确认；高级区动作大、要先勾选风险提示。这一页把每个功能用大白话讲一遍。

## 🟢 新手区

定位：**默认不启用、无需风险确认**。里面的功能都是“改了更好用，改错了也能还原”的类型。

### Win11 经典右键菜单

Win11 的右键菜单藏了一层“显示更多选项”，很多人觉得反人类。这个开关帮你切回 Win10 风格的经典右键菜单，点一下右键所有选项直接出来。

### 任务栏 / 资源管理器微调

对任务栏和资源管理器里一些碍眼的小细节做调整，让日常操作更顺手。

### 关闭广告 / 遥测 / 通知推荐

Windows 里时不时冒出来的推荐内容、广告位和遥测上报，这个功能按公开的注册表口径把它们关掉。键位口径参考了开源项目 Win11Debloat 的公开清单。

### 安全 UWP 卸载（白名单）

卸载 Win11 预装的那些用不上的 UWP 应用。为了防误删，程序内置了一份**白名单**：系统关键组件不在可卸载范围内，不用担心把系统卸坏。白名单同样参考了 Win11Debloat 的公开清单。

### 电源 / 索引 / 自动播放 / 缩略图优化

一组针对常见性能与体验细节的一键优化项，包括电源方案、搜索索引、自动播放和缩略图相关设置。

### 一键还原

在新手区里改过的东西，可以用一键还原恢复回去。改之前不用慌，反悔药是现成的。

## 🟡 高级区

定位：**勾选风险提示后解锁**。里面的功能对系统影响更大，所以程序会先让你确认自己知道在干什么。

### Windows 更新暂停期限 / 禁用

Windows 更新有时候来得不是时候。这个功能可以调整更新的暂停期限，或直接将其禁用。注册表 / 命令口径参考了 Sophia Script 的公开脚本。

### 一键还原

和新手区一样，高级区的改动也支持一键还原。

<VTDocWarning>
高级区涉及 Windows 更新策略，改动前请确认你理解后果。所有操作仍需手动确认后才执行，但“确认了再执行”不等于“执行了没影响”，请按需使用。
</VTDocWarning>

## 小提示

- 每个开关旁边都有人话说明，不确定的先看说明再动手；
- 所有操作都会被记录到日志（INFO / WARN / ERROR），出了问题可以翻日志对照；
- 改完不满意，优先用对应分区的“一键还原”。
