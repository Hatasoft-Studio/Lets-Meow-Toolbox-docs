# 功能分区

程序里的功能不是一股脑堆在一起的，而是按“风险高低、用途不同”分成了几个区。这一页给你一张总览图，每个区的详细用法点对应链接进去看。

## 一张表看懂所有分区

| 分区 | 定位 | 里面有什么 |
| --- | --- | --- |
| 🟢 新手区 | 默认不启用、无需风险确认 | Win11 经典右键菜单、任务栏/资源管理器微调、关闭广告/遥测/通知推荐、安全 UWP 卸载（白名单）、电源/索引/自动播放/缩略图优化、一键还原 |
| 🟡 高级区 | 勾选风险提示后解锁 | Windows 更新暂停期限/禁用、一键还原 |
| 📦 卸载程序 | 独立页面 | Win32 软件批量卸载、残留扫描与清理、导出清理报告，与「解除占用」联动 |
| 🔓 解除占用 | 独立页面 | 查找占用进程、关闭程序释放占用、开机延迟删除 |
| 🔴 高危插件区 | 外置 DLL 插件 | 关闭 Defender / 关闭防火墙 / 移除 Edge·WebView2。主程序本体不含任何高危代码，仅动态加载 `plugins` 目录下的插件 DLL |
| ⚙️ 设置 | 独立页面 | 外观、配置预设导入导出、日志目录、一键初始化全部内容、关于与更新日志 |
| 💖 特别鸣谢 | 独立页面 | 本项目集成的其他开源项目 |

## 为什么这么分

- **新手区**里的操作都比较温和，所以不需要你勾选什么风险确认，适合刚装完系统的朋友；
- **高级区**里的操作影响更大（比如动 Windows 更新），所以要先勾选风险提示才会解锁；
- **卸载程序**和**解除占用**自 v0.1.1 起从原来的分区里拆了出来，各自成为独立的导航分类和独立页面，用起来更顺手；
- **高危插件区**最特殊：这些功能（关 Defender、删 Edge 之类）风险高，所以作者把它们全部做成了**外置插件**，主程序本身一行高危代码都没有。你不用插件，程序就完全不含这些功能。

## 所有分区都遵守的安全底线

- 所有修改、删除、清理操作**均需用户手动确认**，没有任何自动执行逻辑；
- 残留、占用项**默认不勾选**，想清理得你自己勾上；
- 内置黑名单：`C:\Windows`、`System32`、`WinSxS` 等系统核心目录与系统核心进程禁止强制结束；
- 程序不加壳、不混淆，底层只调用微软原生 Win32 API（RestartManager、MoveFileEx、Registry 等），代码全部开源可查。
