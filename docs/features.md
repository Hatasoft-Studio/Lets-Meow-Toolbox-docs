# 功能分区

程序按风险与用途划分为以下分区。所有修改、删除、清理操作**均需用户手动确认**，无任何自动执行逻辑；残留、占用默认不勾选。

| 分区 | 定位 | 说明 |
| --- | --- | --- |
| 🟢 新手区 | 默认不启用、无需风险确认 | Win11 经典右键菜单、任务栏/资源管理器微调、关闭广告/遥测/通知推荐、安全 UWP 卸载（白名单）、电源/索引/自动播放/缩略图优化、一键还原 |
| 🟡 高级区 | 勾选风险提示后解锁 | Windows 更新暂停期限/禁用、一键还原 |
| 📦 卸载程序 | 独立页面 | Win32 软件批量卸载、残留扫描与清理、导出清理报告，与「解除占用」联动 |
| 🔓 解除占用 | 独立页面 | 查找占用进程、关闭程序释放占用、开机延迟删除 |
| 🔴 高危插件区 | 外置 DLL 插件 | 关闭 Defender / 关闭防火墙 / 移除 Edge·WebView2。**主程序本体不含任何高危代码**，仅动态加载 `plugins` 目录下的插件 DLL |
| ⚙️ 设置 | 独立页面 | 外观、配置预设导入导出、日志目录、一键初始化全部内容、关于与更新日志 |
| 💖 特别鸣谢 | 独立页面 | 本项目集成的其他开源项目 |

## 🟢 新手区

默认不启用、无需风险确认，适合刚装完系统的新手：

- **Win11 经典右键菜单**：切换回经典 Win10 右键菜单
- **任务栏 / 资源管理器微调**
- **关闭广告 / 遥测 / 通知推荐**
- **安全 UWP 卸载**：基于白名单，避免误删系统组件
- **电源 / 索引 / 自动播放 / 缩略图优化**
- **一键还原**

## 🟡 高级区

勾选风险提示后解锁：

- **Windows 更新暂停期限 / 禁用**
- **一键还原**

## 📦 卸载程序（独立页面）

自 v0.1.1 起，「卸载程序」从新手区/高级区拆出，成为独立导航分类与独立页面：

- Win32 软件批量卸载
- 残留扫描与清理
- 导出清理报告
- 与「解除占用」联动

## 🔓 解除占用（独立页面）

自 v0.1.1 起同样独立为一个导航分类与独立页面：

- 查找占用进程
- 关闭程序释放占用
- 开机延迟删除

## 🔴 高危插件区

高危功能全部以外置 DLL 插件形式提供，**主程序本体不含任何高危代码**，仅动态加载 `plugins` 目录下的插件 DLL。当前官方高危插件提供：

- 关闭 Defender
- 关闭防火墙
- 移除 Edge · WebView2

<VTDocNote>
若高危插件区没有内容，说明程序同级目录下还没有放入插件 DLL；将高危插件 DLL 放入 `plugins` 目录后才会加载。
</VTDocNote>

## ⚙️ 设置（独立页面）

- 外观设置
- 配置预设导入 / 导出
- 日志目录
- **一键初始化全部内容**（v0.1.1 新增）：还原全部功能设置到默认状态、复位外观设置、清空配置预设
- 关于与更新日志（关于页显示当前版本，可一键「查看更新日志」与「前往 GitHub 仓库」）

## 💖 特别鸣谢（独立页面）

展示本项目参考与集成的开源项目，每个条目附「访问」按钮，可一键打开该项目主页 / GitHub 仓库。详见[特别鸣谢页](/Contributor.html)。
