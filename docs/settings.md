# 设置与关于

设置页管的是程序自己的“家务事”：语言、软件更新、外观、配置、日志和版本信息。v0.2.0 起设置页顶部新增了**语言**与**软件更新**两张卡片，这一页按卡片顺序逐个讲清楚。

## 语言 / Language

v0.2.0 开始，程序支持**外置语言包**。规则很简单：

- **简体中文是源语言**，直接内嵌在程序本体里，就算一个语言包都没装，界面也不会变成外文；
- 其他语言（繁体中文、日语、英语等）以 `.meowlang` 文件的形式放在程序目录下的 `lang` 文件夹里，启动时自动扫描；
- 官方语言包（繁体中文、日语、英语）随程序一起发布，解压后就在 `lang` 目录里，不用另外下载。

语言卡片上会显示“当前语言：xxx”，下面有两个按钮。

### 选择语言

点「选择语言」会打开独立的「语言管理」窗口：

- 窗口顶部显示语言包目录的完整路径；
- 列表会列出 `lang` 目录下的全部语言包，顺序是：内嵌简体中文 → 官方语言包 → 第三方语言包，再按名称排序；
- 选中某一项后可以查看它的详情（包名、制作者、版本、适用版本、简介、作者网站等）；
- 点「加载所选语言」后，程序会先检查这个语言包是否适用于当前版本，通过后弹出详情确认，确认加载会**自动重启程序**生效——重启是为了让所有界面文本都重新翻译一遍，属于正常现象。

<VTDocTip>
语言包加载失败时，程序会告诉你原因（例如“该语言包适用于 0.1.2，当前软件版本为 v0.2.0”），并写入日志，不会静默失败。
</VTDocTip>

### 安装语言包

点「安装语言包」会打开文件选择框，选中一个 `.meowlang` 文件后，按下面的流程走：

1. **读取与校验**：检查 `id`、`name`、`author`、`version`、`strings` 这些必填字段是否齐全，格式坏了会直接报错并写日志；
2. **版本兼容检查**：语言包声明的适用版本必须匹配当前程序版本，否则拒绝安装；
3. **详情确认**：弹窗展示包名、制作者、适用版本、安装时间、语言类型、语言编码、文件大小、简介与作者网站；官方语言包的制作者旁边会带一个**绿色盾牌标识**；
4. **第三方确认**：如果制作者/作者网站不是官方（`Hatasoft-Studio` + 官方站点），会再弹一次“该语言包由第三方个人制作者/社区提供，是否继续安装？”；
5. **进度窗口**：带进度条地复制语言包到 `lang` 目录；
6. **结果提示**：成功时提示「语言包安装成功！」，失败时显示失败原因和日志文件路径。

安装完成后，可以在「选择语言」里切换到刚装好的语言。

### 同名语言包的更新 / 降级

如果 `lang` 目录里已经存在同名的语言包，安装时会：

- 先比较版本号，告诉你这次是**更新**、**降级**还是**重新安装**，并二次确认；
- 如果新旧语言包的**作者或作者网站不一致**，程序会直接拒绝覆盖，并提示你手动删除旧语言包后再装——这是为了防止有人拿别人的语言包 ID 做覆盖投放。

### 适用范围怎么写

语言包的 `appVersion` 字段决定它能用在哪些版本上：

| 写法 | 含义 |
| --- | --- |
| `*` 或留空 | 所有版本都适用 |
| `>=0.2.0` | v0.2.0 及之后的版本 |
| `0.2.0 \| 0.2.1 \| 0.2.2` | 仅这几个版本适用（v0.2.0 起支持用 `\|` 分隔多个版本号） |
| `<0.3.0` | v0.3.0 之前的版本 |

也支持 `>=`、`<=`、`>`、`<`、`=` 与 `*`，多个条件可以用空格或逗号组合（需要同时满足）。看不懂也没关系——装不上时程序会把原因写出来。

## 软件更新

v0.2.0 新增了「软件更新」卡片，里面就一个「检查更新」按钮。

点一下之后，程序会向官方更新接口（`https://api.lets-meow-toolbox.hatasoft365.top/`）请求最新版本号、下载地址、更新说明与「已停止支持的版本列表」，然后：

- **有新版本**：弹窗展示当前版本、最新版本、版本号、更新内容，以及「前往官网获取新版本」按钮；不想马上更新可以点「稍后再说」；
- **已是最新**：按钮旁边直接提示「当前已是最新版本（v0.2.0）」；
- **网络失败或接口异常**：提示「检查更新失败：原因」，不影响程序继续使用，过一会儿再试即可。

<VTDocWarning>
**停止支持版本检测：** 如果接口返回的“不受支持版本列表”里包含你正在用的版本，程序在**启动时**就会弹出强制更新提示，标题是「此版本已停止支持」，只能选择「前往官网获取新版本」或「退出程序」——更新前无法继续使用。这是为了让旧版本彻底退场，避免已知问题继续被使用。
</VTDocWarning>

## 外观

程序自带多套主题画笔，包括浅色主题与**二次元模式**（没错，这是一个二次元现代化 UI 的工具箱，壁纸与配色都是配套的）。

- 非 Win11 系统上，窗口背景可能会自动回退为纯色，这是预期行为，不影响使用；
- v0.1.1 优化过二次元模式下开关与按钮的颜色、文字可读性，老版本觉得字淡的建议升级。

## 配置预设导入 / 导出

你在程序里做的功能设置，可以导出成 `.meowpreset` 预设文件保存；换电脑或重装系统后，再导入回来，不用重新一个个勾。

## 日志目录

程序内置全局日志（v0.1.1 起改为全局记录）：你的全部设置操作、执行结果与时间都会按 INFO / WARN / ERROR 级别记下来，不再是空文件。

- 日志位置：`%LocalAppData%\LetsMeowToolbox\logs\meow-日期.log`
- 资源管理器地址栏粘贴 `%LocalAppData%\LetsMeowToolbox\logs` 回车即可打开。
- 语言包安装失败、更新检查失败也会写进这份日志。

## 一键初始化全部内容

v0.1.1 新增的“后悔药总开关”，一键完成三件事：

1. 还原全部功能设置到默认状态；
2. 复位外观设置；
3. 清空配置预设。

想把程序恢复到“刚装好”的状态，用这个就行。

<VTDocNote>
一键初始化**不会**删除你安装的语言包，语言包只存在于 `lang` 目录里。想彻底移除某个语言，直接到 `lang` 目录删掉对应的 `.meowlang` 文件即可。
</VTDocNote>
