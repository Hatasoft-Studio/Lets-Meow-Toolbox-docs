# 解除占用

“文件正在被另一个程序使用，无法删除”——遇到这个提示时，这个页面就是你的救星。“解除占用”自 v0.1.1 起也是**独立的导航分类和独立页面**。

## 它能干什么

### 查找占用进程

指定一个被占用的文件或目录，帮你查出到底是哪个进程在占用它。

### 关闭程序释放占用

找到占用进程后，可以将其关闭来释放占用。关闭之后，刚才删不掉的文件就能正常删除了。

**注意**：系统核心进程在内置黑名单里，**禁止强制结束**，不用担心手滑把系统搞崩。

### 开机延迟删除

有些文件实在顽固，当前怎么都删不掉。这个功能会安排它在**下次开机时删除**——系统启动早期文件还没被占用，删除就能成功。底层用的是 Windows 原生的文件操作能力（如 MoveFileEx 的延迟操作机制）。

## 和卸载程序的联动

卸载软件时遇到“文件被占用”，可以直接转到这个页面处理占用，再回去继续清理。两个页面是设计好联动的。

## 使用建议

1. 先在占用页面查清楚是**谁**在占用，别上来就关进程——万一是你没保存的文档呢；
2. 确认进程可以关，再执行关闭；
3. 实在删不掉的，用开机延迟删除兜底；
4. v0.1.2 修复了小窗口下占用进程列表高度塌陷、滚轮被吞的问题，现在列表可以随整页正常滚动，版本旧的建议升级。

<VTDocTip>
底层实现只调用微软原生 Win32 API（RestartManager、MoveFileEx 等），不依赖第三方驱动或魔法，代码开源可查。
</VTDocTip>
