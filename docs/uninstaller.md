# 卸载程序

“卸载程序”自 v0.1.1 起是一个**独立的导航分类和独立页面**，专门对付“软件装了一堆、卸不干净”的问题。

## 它能干什么

### Win32 软件批量卸载

列出系统里已安装的 Win32 软件，可以一次勾选多个批量卸载，不用一个个进控制面板慢慢点。

### 残留扫描与清理

软件卸载之后，往往还会留下一堆注册表项和文件夹残留。这个功能会扫描这些残留，让你勾选后清理掉。

**注意**：残留项**默认是不勾选的**。程序的态度是“宁可少删，不可误删”，你要清理哪些，得自己看清楚了再勾。

### 导出清理报告

卸载和清理的过程可以导出成报告，方便你留档或者排查问题。

### 与「解除占用」联动

卸载时最怕“文件被占用删不掉”。这个页面和[解除占用](/docs/unlock.html)是联动的，遇到占用问题可以直接借助解除占用页处理。

## 设计上参考了谁

卸载与残留扫描模块的设计思路，参考了开源项目 **Bulk Crap Uninstaller（BCU，GPL-3.0）** 的卸载注册表读取与残留检测方案——但注意是**独立实现**，不是照搬代码。

## 使用建议

<VTDocSteps>
  <VTDocStep title="先勾选要卸载的软件">
    在列表里勾选目标软件。看准了再勾，批量卸载一旦开始就是按顺序执行。
  </VTDocStep>
  <VTDocStep title="执行卸载并逐项确认">
    卸载与后续的清理操作都会经过你的手动确认，不会自动动手。
  </VTDocStep>
  <VTDocStep title="扫描残留，按需勾选">
    卸载完成后扫描残留。残留默认不勾选，确认无误后再选择清理。
  </VTDocStep>
  <VTDocStep title="导出报告留档">
    需要的话导出清理报告，方便日后回溯。
  </VTDocStep>
</VTDocSteps>

<VTDocNote>
系统核心目录（C:\Windows、System32、WinSxS）在程序的内置黑名单里，不会被当成残留误删。
</VTDocNote>
