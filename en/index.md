## Quick Start

<VTDocSteps>
  <VTDocStep title="Pick a Version">
    Open the download page; it automatically fetches the latest versions from GitHub and recommends a package for your system architecture.
  </VTDocStep>
  <VTDocStep title="Download the Package">
    Click the main button to download the recommended version; if the download is slow, switch to the mirror line.
  </VTDocStep>
  <VTDocStep title="Run It">
    For the installer version, just double-click to install; for the portable version, extract it and run the executable directly.
  </VTDocStep>
</VTDocSteps>

<VTDocTip>
  The current latest version and all historical versions are published on GitHub Releases; you can also head straight to the repository to check the release notes.
</VTDocTip>
