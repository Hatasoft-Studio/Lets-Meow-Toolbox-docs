## Open Source Projects Acknowledged

This project references and acknowledges the following open source projects (consistent with the in-app "💖 Special Thanks" page; each entry has a "Visit" button):

<VTDocCardGroup cols="2">
  <VTDocCard title="HandyControl · MIT" icon="star" href="https://github.com/HandyOrg/HandyControl">
    The entire modern card UI and controls of this toolbox (Card, Dialog, Growl, theme switching) are built on HandyControl.
  </VTDocCard>
  <VTDocCard title="Open-Shell · MIT" icon="star" href="https://github.com/Open-Shell/Open-Shell-Menu">
    The "switch to the classic Win10 context menu" feature of this tool references the registry approach from the Open-Shell community for bringing back the Win11 context menu.
  </VTDocCard>
  <VTDocCard title="Bulk Crap Uninstaller · GPL-3.0" icon="star" href="https://github.com/Klocman/Bulk-Crap-Uninstaller">
    The design of the "software uninstall / leftover scan" module of this tool references BCU's uninstall registry reading and leftover detection approach, and is an independent implementation.
  </VTDocCard>
  <VTDocCard title="Win11Debloat · MIT" icon="star" href="https://github.com/Raphire/Win11Debloat">
    The preinstalled UWP uninstall whitelist and the registry keys for "disabling ads/telemetry/notification suggestions" of this tool reference Win11Debloat's public lists.
  </VTDocCard>
  <VTDocCard title="Sophia Script · CC-BY-NC-SA-4.0" icon="star" href="https://github.com/farag2/Sophia-Script">
    The registry / sc command conventions used by some system settings of this tool (pause updates, service management) reference Sophia Script's public scripts.
  </VTDocCard>
  <VTDocCard title="EZ-Mirror" icon="rocket" href="https://mirror.hatasoft365.top/">
    EZ-Mirror provides accelerated download service for this project's GitHub repository, improving the user experience.
  </VTDocCard>
</VTDocCardGroup>
