# 初心者エリアと上級エリア

この 2 つのエリアはプログラム内で「システムチューニング」を担う主力です。初心者エリアは穏やかで確認不要、上級エリアは動作が大きく、先にリスク提示へのチェックが必要です。このページでは各機能をわかりやすい言葉で説明します。

## 🟢 初心者エリア

位置づけ：**デフォルトで無効、リスク確認不要**。中の機能はすべて「変更するとより使いやすく、間違えても復元できる」タイプです。

### Win11 クラシック右クリックメニュー

Win11 の右クリックメニューは「その他のオプションを表示」が一段階挟まり、多くの方が使いにくいと感じています。このスイッチで Win10 スタイルのクラシック右クリックメニューに切り替え、右クリック一回で全オプションが直接表示されます。

### タスクバー / エクスプローラーの微調整

タスクバーやエクスプローラーの気になる細部を調整し、日常操作をより快適にします。

### 広告 / テレメトリ / 通知のおすすめを無効化

Windows に時折現れるおすすめコンテンツ、広告枠、テレメトリ送信を、公開されているレジストリ基準に基づいて無効化します。キーの基準はオープンソースプロジェクト Win11Debloat の公開リストを参考にしています。

### 安全な UWP アンインストール（ホワイトリスト）

Win11 にプレインストールされた使わない UWP アプリをアンインストールします。誤削除を防ぐため、プログラムには**ホワイトリスト**が内蔵されています：システムの重要コンポーネントはアンインストール対象外なので、システムを壊す心配はありません。ホワイトリストも同様に Win11Debloat の公開リストを参考にしています。

### 電源 / インデックス / 自動再生 / サムネイルの最適化

よくあるパフォーマンスと体験の細部に対するワンクリック最適化項目群で、電源プラン、検索インデックス、自動再生、サムネイル関連の設定を含みます。

### ワンクリック復元

初心者エリアで変更した内容は、ワンクリック復元で元に戻せます。変更前に慌てる必要はありません。やり直しの手段はちゃんと用意されています。

## 🟡 上級エリア

位置づけ：**リスク提示にチェックするとロック解除**。中の機能はシステムへの影響が大きいため、プログラムはまず自分が何をしているか理解しているかの確認を求めます。

### Windows Update 一時停止期限 / 無効化

Windows Update は時に都合の悪いタイミングで来ます。この機能は更新の一時停止期限を調整したり、直接無効化したりできます。レジストリ / コマンドの基準は Sophia Script の公開スクリプトを参考にしています。

### ワンクリック復元

初心者エリアと同様、上級エリアの変更もワンクリック復元に対応しています。

<VTDocWarning>
上級エリアは Windows Update ポリシーに関わります。変更前に結果を理解していることを確認してください。全操作は依然として手動確認後に実行されますが、「確認してから実行」は「実行しても影響がない」ことを意味しません。必要に応じて使用してください。
</VTDocWarning>

## ヒント

- 各スイッチの横にはわかりやすい説明があります。不確かな場合はまず説明を読んでから操作を。
- 全操作はログに記録されます（INFO / WARN / ERROR）。問題が起きたらログを見比べて確認できます。
- 変更後に満足できなかったら、優先的に対応するエリアの「ワンクリック復元」を使ってください。
