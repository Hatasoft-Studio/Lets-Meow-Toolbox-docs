# 高リスクプラグインエリア

ここはプログラム全体で最も「よく確認してから手を動かす」必要がある場所です。まず結論：**メインプログラム本体には高リスクコードは一切含まれておらず**、全高リスク機能は外部プラグインです。プラグインを置かなければ、ここは空のままです。

## なぜ高リスク機能をプラグインにしたのか

作者の設計原則は明確です：高リスク操作（ウイルス対策の無効化、システムコンポーネントの取り外しなど）はメインプログラムに混ぜてはならない。そのため、それらはすべて**外部 DLL プラグイン**に分離され、プログラムと同じ階層の `plugins` ディレクトリに置かれ、メインプログラムが動的に読み込みます。

こうする利点：

- メインプログラム（`LetsMeowToolbox.exe`）は自由に審査でき、中には高リスクコードは一行もありません。
- 高リスク機能が不要なら、プラグインを置かなければよく、お互いに干渉しません。
- プラグインを削除すればそのまま除去、すっきり。

## 公式高リスクプラグインの操作

リポジトリに同梱される公式高リスクプラグイン（`LetsMeowToolbox.Plugins.HighRisk`）には 3 つの操作が含まれます：

| 操作 | 説明 |
| --- | --- |
| Defender の無効化 | Windows Defender の保護を無効化 |
| ファイアウォールの無効化 | Windows ファイアウォールを無効化 |
| Edge ・ WebView2 の削除 | Edge ブラウザと WebView2 コンポーネントを削除 |

## 有効化の方法

リリースパッケージには `plugins` ディレクトリが同梱されています。公式高リスクプラグインの DLL（`LetsMeowToolbox.Plugins.HighRisk.dll`）は公式リリースフローでそのディレクトリにコピーされます。お手元のバージョンの `plugins` ディレクトリが空の場合は、高リスクプラグインの DLL をそこに入れ、プログラムを開き直せば読み込まれます。

## 使用前に必ず知っておくべきこと

<VTDocWarning>
高リスク操作が高リスクと呼ばれるのは、本当にシステムのセキュリティと安定性に影響するからです：

- Defender / ファイアウォールの無効化はパソコンの保護を失わせます。
- Edge / WebView2 の削除は WebView2 に依存するプログラムに影響する可能性があります。

各操作は有効化前に**リスク提示文を表示し、再確認を求めます**。本当に読み終えてから確認をクリックしてください。プラグイン契約はあらゆる「自動実行、自動確認、無提示」ロジックを明確に禁止しており、知らないうちに高リスク操作が実行されることはありません。
</VTDocWarning>

- 全高リスク操作は**手動確認後**に実行されます。
- 管理者権限が必要な操作は追加で管理者権限を要求します。
- 各操作は**復元**機能を提供し、有効化後に異常があれば復元できます。
- 操作結果はログに記録され、振り返りに便利です。

## 自分で高リスクプラグインを書きたい場合

プログラムはプラグイン契約を公開しており、サードパーティの高リスクプラグイン開発を許可しています（リスクは自己責任）。開発ドキュメントは[高リスクプラグイン開発](/ja/dev/high-risk-plugin-development.html)をご覧ください。
