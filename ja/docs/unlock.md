# 占用解除

「ファイルは別のプログラムで使用されているため、削除できません」——この表示に出会ったら、このページが救世主です。「占用解除」も v0.1.1 から**独立したナビゲーション分類と独立ページ**になっています。

## 何ができるのか

### 占用プロセスの検索

占用されているファイルやディレクトリを指定すると、どのプロセスが占用しているかを調べます。

### プログラムを終了して占用を解放

占用プロセスを見つけたら、それを終了して占用を解放できます。終了後、先ほど削除できなかったファイルを通常どおり削除できます。

**注意**：システムコアプロセスは内蔵ブラックリストに含まれており、**強制終了は禁止**されています。誤操作でシステムをクラッシュさせる心配はありません。

### 起動時遅延削除

どうしても削除できない頑固なファイルもあります。この機能は**次回の起動時に削除**するよう手配します——システム起動の早い段階ではファイルはまだ占用されていないため、削除が成功します。内部では Windows 純正のファイル操作機能（MoveFileEx の遅延操作メカニズムなど）を使用しています。

## プログラムのアンインストールとの連携

ソフトウェアのアンインストール時に「ファイルが占用されている」問題に遭遇したら、直接このページに移動して占用を処理し、その後戻ってクリーンアップを続行できます。2 つのページは連携するよう設計されています。

## 利用の提案

1. まず占用ページで**誰が**占用しているかを調べること。いきなりプロセスを終了しないでください——もしかしたら未保存のドキュメントかもしれません。
2. プロセスを終了してよいことを確認してから、終了を実行。
3. それでも削除できないものは、起動時遅延削除を最終手段に。
4. v0.1.2 では、小さいウィンドウ時に占用プロセス一覧の高さが潰れ、ホイールが飲み込まれる問題を修正しました。現在、リストはページ全体とともに正常にスクロールできます。古いバージョンをお使いの方はアップグレードを推奨します。

<VTDocTip>
内部実装は Microsoft 純正の Win32 API（RestartManager、MoveFileEx など）のみを呼び出し、サードパーティのドライバや魔法には依存せず、コードはオープンソースで確認可能です。
</VTDocTip>
