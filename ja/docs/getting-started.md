# クイックスタート

このページではゼロから Let's Meow! Toolbox をダウンロードして起動する方法を案内します。専門知識は一切不要、クリックしていくだけで大丈夫です。

## まずお使いのパソコンが要件を満たしているか確認

- **システム**：Windows 10 または Windows 11（この 2 つのみ対応、Win7/8 は不可）
- **アーキテクチャ**：64 ビット（x64）
- その他はありません。ランタイムの事前インストールが必要かどうかは、どのバージョンをダウンロードするかで決まります。後述します。

## ステップ 1：ダウンロードページでインストーラーを入手

サイト上部の[ダウンロード](/ja/download.html)を開きます。このページは **GitHub 上の全バージョンを自動的に検索**するので、手動でリンクを探す必要はありません：

- 「更新チャンネル」は **Release**（正式版）と **Pre Release**（プレリリース版）の 2 種類。普段使いなら Release で十分です。
- 「バージョン」ドロップダウンにはそのチャンネルの全バージョンが並び、最新版が最上部に表示されます。より古いバージョンも選択可能です。
- ページはお使いのパソコンに基づき、最適なインストーラーを大きなボタンとして最も目立つ位置に配置します。
- あるバージョンにインストール版が提供されていない場合、インストール版ボタンは自動的に非表示になります。これは正常な動作です。

ダウンロード回線は 2 つあります：

1. **GitHub**：公式チャンネル。GitHub のサーバーは海外にあるため、ダウンロードが遅くなることがあります。
2. **EZ-Mirror ミラー**：ダウンロードが遅い場合はこの回線に切り替えてください。[EZ-Mirror](https://mirror.hatasoft365.top/) が高速化を提供します。

<VTDocNote>
Pre Release（プレリリース）バージョンは **GitHub からしかダウンロードできません**。ミラーサイトはプレリリースバージョンを同期しないため、Pre Release チャンネル選択時は回線切り替えが表示されません。
</VTDocNote>

## ステップ 2：2 種類の「ポータブル版」の違いを理解する

各バージョンには通常 2 つの zip があり、ファイル名は長いですが、違いは実はシンプルです：

| ファイル名のキーワード | ページ上の名称 | サイズ | .NET の事前インストール | 一言で説明 |
| --- | --- | --- | --- | --- |
| `framework-dependent` | ポータブル軽量版 | 小、約 10~20 MB | 必要 | 本体は小さいが、パソコンに .NET 8 デスクトップランタイムのインストールが必要 |
| `self-contained` | ポータブル完全版 | 大、約 90~110 MB | 不要 | ランタイムも一緒にパッケージ済み、何もインストール不要 |

どちらを選ぶべきかわからない？**面倒なのが嫌なら大きい方（ポータブル完全版）を選べば**、ダブルクリックですぐに使えます。

バージョンによっては `.exe` インストーラー（ファイル名に `installer-version` を含む）が追加である場合があります。これは本質的に「ポータブル完全版」のインストーラーで、インストールウィザードを進めたい方はこちらをどうぞ。ただし**すべてのバージョンにインストーラーがあるわけではありません**。ダウンロードページに実際に表示されるものが基準です。

## ステップ 3：実行する

**ポータブル版（zip）**：

1. zip を任意のディレクトリに解凍（例：`D:\Tools\LetsMeowToolbox`）。
2. 中の `LetsMeowToolbox.exe` をダブルクリックするだけで完了。

**インストーラー（exe）**：ダブルクリック後、ウィザードに従って「次へ」を進めるだけです。

<VTDocTip>
解凍すると `plugins` フォルダと `lang` フォルダが表示されます：`plugins` は高リスクプラグイン、`lang` は言語パックを置く場所です。メインプログラム自体には高リスクコードは一切含まれておらず、高リスク機能はすべて `plugins` 内の外部プラグインによるものです。詳しくは[高リスクプラグインエリア](/ja/docs/high-risk-zone.html)をご覧ください。
</VTDocTip>

## ステップ 4：必要に応じて言語を切り替える（v0.2.0 から）

プログラムのデフォルトは簡体字中国語です。公式には繁体字中国語、日本語、英語の 3 つの言語パックが同梱され、`lang` ディレクトリに置かれています：

1. 「設定」ページの**言語 / Language**カードを開きます。
2. 「言語を選択」をクリックして言語管理ウィンドウを開きます。
3. 希望の言語を選択し、「選択した言語を読み込む」をクリックすると、確認後にプログラムが自動再起動します——1 回再起動すれば反映されます。

他の人が作った言語パックをインストールしたい場合は、「言語パックをインストール」をクリックして `.meowlang` ファイルを選択するだけです。詳しい流れは[設定とバージョン情報](/ja/docs/settings.html)をご覧ください。

## ダブルクリックしても反応がない場合

十中八九、「ポータブル軽量版」をダウンロードしたのにパソコンにランタイムが入っていないことが原因です。解決策は 2 つ、どちらでも構いません：

1. [.NET 8 デスクトップランタイム](https://dotnet.microsoft.com/download/dotnet/8.0)をインストール（".NET Desktop Runtime 8.x" を選択）し、インストール完了後にプログラムを起動。
2. または直接「ポータブル完全版」に切り替える。ランタイムを内蔵しています。

その他のケースは[よくある質問](/ja/docs/faq.html)をご覧ください。

## ついでに一言

プログラムの全変更・削除・クリーンアップ操作は**実行前に必ず確認を求められ**、勝手に自動実行されることはありません。残留項目と占用項目もデフォルトではチェックされておらず、安心していろいろ試せます。
