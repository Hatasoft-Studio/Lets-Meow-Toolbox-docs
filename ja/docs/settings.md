# 設定とバージョン情報

設定ページはプログラム自身の「家事」を管理します：外観、構成、ログ、バージョン情報。このページでは各項目を明確に説明します。

## 外観

プログラムは複数のテーマブラシを内蔵し、ライトテーマと**二次元モード**を含みます（そう、これは二次元モダン UI のツールボックスで、壁紙と配色も揃っています）。

- 非 Win11 システムでは、ウィンドウ背景が自動的に単色にフォールバックすることがありますが、これは想定された動作で、使用には影響しません。
- v0.1.1 では二次元モード時のスイッチとボタンの色、文字の可読性を最適化しました。古いバージョンで文字が薄いと感じる方はアップグレードを推奨します。

## 構成プリセットのインポート / エクスポート

プログラム内で行った機能設定は、プリセットファイルとしてエクスポートして保存できます。パソコンの買い替えやシステムの再インストール後にインポートして復元でき、一つずつチェックし直す必要はありません。

## ログディレクトリ

プログラムはグローバルログを内蔵（v0.1.1 からグローバル記録に変更）：全設定操作、実行結果、時刻が INFO / WARN / ERROR レベルで記録され、空ファイルではなくなりました。

- ログの場所：`%LocalAppData%\LetsMeowToolbox\logs\meow-日付.log`
- エクスプローラーのアドレスバーに `%LocalAppData%\LetsMeowToolbox\logs` を貼り付けて Enter すると開けます。

## ワンクリックで全内容を初期化

v0.1.1 で追加された「やり直しの総合スイッチ」で、ワンクリックで 3 つのことを行います：

1. 全機能設定をデフォルト状態に復元。
2. 外観設定をリセット。
3. 構成プリセットをクリア。

プログラムを「インストールしたて」の状態に戻したいときは、これを使ってください。

## バージョン情報と更新履歴

バージョン情報ページで確認できるもの：

- **現在のバージョン番号**（v0.1.1 からバージョン番号体系を導入：メジャー番号.マイナー番号.リビジョン番号）。
- **「更新履歴を表示」ボタン**：プログラムのウィンドウ内で各バージョンの更新内容を直接確認。
- **GitHub リポジトリ情報と「GitHub リポジトリへ」ボタン**：ワンクリックで公式リポジトリ <https://github.com/Hatasoft-Studio/Lets-Meow-Toolbox> を開きます。
