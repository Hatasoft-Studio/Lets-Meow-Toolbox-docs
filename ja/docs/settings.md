# 設定とバージョン情報

設定ページはプログラム自身の「家事」を管理します：言語、ソフトウェア更新、外観、構成、ログ、バージョン情報。v0.2.0 から設定ページ上部に**言語**と**ソフトウェア更新**の 2 つのカードが追加されました。このページではカードの順に沿って一つずつ説明します。

## 言語 / Language

v0.2.0 から、プログラムは**外部言語パック**に対応しました。ルールはシンプルです：

- **簡体字中国語はソース言語**で、プログラム本体に直接組み込まれています。言語パックを一つもインストールしていなくても、画面が外国語になることはありません。
- その他の言語（繁体字中国語、日本語、英語など）は `.meowlang` ファイルとしてプログラムディレクトリの `lang` フォルダに置かれ、起動時に自動的にスキャンされます。
- 公式言語パック（繁体字中国語、日本語、英語）はプログラムと一緒にリリースされ、解凍後は `lang` ディレクトリにあります。別途ダウンロードする必要はありません。

言語カードには「現在の言語：xxx」が表示され、その下に 2 つのボタンがあります。

### 言語を選択

「言語を選択」をクリックすると、独立した「言語管理」ウィンドウが開きます：

- ウィンドウ上部に言語パックディレクトリの完全なパスが表示されます。
- リストには `lang` ディレクトリ内のすべての言語パックが表示されます。順序は：組み込み簡体字中国語 → 公式言語パック → サードパーティ言語パック、その後名前順です。
- 項目を選択すると、その詳細（パッケージ名、制作者、バージョン、適用バージョン、概要、作者サイトなど）を確認できます。
- 「選択した言語を読み込む」をクリックすると、プログラムはまずこの言語パックが現在のバージョンに適用できるか確認し、通過したら詳細確認ダイアログを表示します。読み込みを確認すると**プログラムが自動的に再起動**して反映されます——再起動はすべての画面テキストを新しく翻訳し直すためで、正常な動作です。

<VTDocTip>
言語パックの読み込みに失敗した場合、プログラムは理由（例：「この言語パックは 0.1.2 に適用され、現在のソフトウェアバージョンは v0.2.0 です」）を表示し、ログに書き込みます。サイレントに失敗することはありません。
</VTDocTip>

### 言語パックをインストール

「言語パックをインストール」をクリックするとファイル選択ダイアログが開きます。`.meowlang` ファイルを選択すると、以下の流れで処理されます：

1. **読み込みと検証**：`id`、`name`、`author`、`version`、`strings` などの必須フィールドが揃っているか確認し、形式が壊れている場合は直接エラーを表示してログに書き込みます。
2. **バージョン互換性チェック**：言語パックが宣言する適用バージョンが現在のプログラムバージョンと一致する必要があり、一致しない場合はインストールを拒否します。
3. **詳細確認**：パッケージ名、制作者、適用バージョン、インストール日時、言語タイプ、言語コード、ファイルサイズ、概要、作者サイトをダイアログで表示します。公式言語パックの制作者の横には**緑色の盾アイコン**が付きます。
4. **サードパーティ確認**：制作者/作者サイトが公式（`Hatasoft-Studio` + 公式サイト）でない場合、「この言語パックはサードパーティの個人制作者/コミュニティによって提供されています。インストールを続行しますか？」と再度確認します。
5. **進捗ウィンドウ**：プログレスバー付きで言語パックを `lang` ディレクトリにコピーします。
6. **結果通知**：成功時は「言語パックのインストールに成功しました！」と表示し、失敗時は失敗理由とログファイルのパスを表示します。

インストール完了後、「言語を選択」でインストールした言語に切り替えられます。

### 同名言語パックの更新 / ダウングレード

`lang` ディレクトリに同名の言語パックが既に存在する場合、インストール時には：

- まずバージョン番号を比較し、今回が**更新**、**ダウングレード**、**再インストール**のどれかを通知し、再確認します。
- 新旧の言語パックの**作者または作者サイトが一致しない**場合、プログラムは上書きを直接拒否し、古い言語パックを手動で削除してからインストールするよう案内します——これは他人の言語パック ID を使って上書き配布することを防ぐためです。

### 適用範囲の書き方

言語パックの `appVersion` フィールドは、どのバージョンで使えるかを決めます：

| 書き方 | 意味 |
| --- | --- |
| `*` または空欄 | すべてのバージョンに適用 |
| `>=0.2.0` | v0.2.0 以降のバージョン |
| `0.2.0 \| 0.2.1 \| 0.2.2` | これらのバージョンのみ適用（v0.2.0 から `\|` 区切りで複数のバージョン番号を指定可能） |
| `<0.3.0` | v0.3.0 より前のバージョン |

`>=`、`<=`、`>`、`<`、`=` と `*` にも対応し、複数の条件はスペースまたはカンマで組み合わせられます（すべて満たす必要があります）。よくわからなくても大丈夫——インストールできない場合はプログラムが理由を表示します。

## ソフトウェア更新

v0.2.0 で「ソフトウェア更新」カードが追加され、中には「更新を確認」ボタンが 1 つだけあります。

クリックすると、プログラムは公式更新インターフェース（`https://api.lets-meow-toolbox.hatasoft365.top/`）に最新バージョン番号、ダウンロードアドレス、更新説明、「サポート終了バージョンリスト」を要求し、その後：

- **新しいバージョンがある**：ダイアログで現在のバージョン、最新バージョン、バージョン番号、更新内容、「公式サイトで新バージョンを入手」ボタンを表示します。今すぐ更新したくない場合は「後で」をクリックできます。
- **既に最新**：ボタンの横に「現在は最新バージョンです（v0.2.0）」と直接表示します。
- **ネットワーク失敗またはインターフェース異常**：「更新の確認に失敗しました：理由」と表示します。プログラムの使用には影響せず、しばらくしてから再試行すれば大丈夫です。

<VTDocWarning>
**サポート終了バージョンの検出：** インターフェースが返す「サポート対象外バージョンリスト」に使用中のバージョンが含まれている場合、プログラムは**起動時**に強制更新プロンプトを表示します。タイトルは「このバージョンはサポートを終了しました」で、「公式サイトで新バージョンを入手」または「プログラムを終了」しか選択できません——更新するまで使用を続けられません。これは旧バージョンを完全に退場させ、既知の問題が使われ続けるのを避けるためです。
</VTDocWarning>

## 外観

プログラムには複数のテーマブラシが付属し、ライトテーマと**二次元モード**を含みます（そう、これは二次元モダン UI のツールボックスで、壁紙と配色も揃っています）。

- 非 Win11 システムでは、ウィンドウ背景が自動的に単色にフォールバックすることがありますが、これは想定された動作で、使用には影響しません。
- v0.1.1 では二次元モード時のスイッチとボタンの色、文字の可読性を最適化しました。古いバージョンで文字が薄いと感じる方はアップグレードを推奨します。

## 構成プリセットのインポート / エクスポート

プログラム内で行った機能設定は `.meowpreset` プリセットファイルとしてエクスポートして保存できます。パソコンの買い替えやシステムの再インストール後にインポートして復元でき、一つずつチェックし直す必要はありません。

## ログディレクトリ

プログラムはグローバルログを内蔵（v0.1.1 からグローバル記録に変更）：全設定操作、実行結果、時刻が INFO / WARN / ERROR レベルで記録され、空ファイルではなくなりました。

- ログの場所：`%LocalAppData%\LetsMeowToolbox\logs\meow-日付.log`
- エクスプローラーのアドレスバーに `%LocalAppData%\LetsMeowToolbox\logs` を貼り付けて Enter すると開けます。
- 言語パックのインストール失敗、更新確認の失敗もこのログに書き込まれます。

## ワンクリックで全内容を初期化

v0.1.1 で追加された「やり直しの総合スイッチ」で、ワンクリックで 3 つのことを行います：

1. 全機能設定をデフォルト状態に復元。
2. 外観設定をリセット。
3. 構成プリセットをクリア。

プログラムを「インストールしたて」の状態に戻したいときは、これを使ってください。

<VTDocNote>
ワンクリック初期化は、インストールした言語パックを**削除しません**。言語パックは `lang` ディレクトリにのみ存在します。ある言語を完全に削除したい場合は、`lang` ディレクトリで該当する `.meowlang` ファイルを直接削除してください。
</VTDocNote>

## バージョン情報と更新履歴

バージョン情報ページで確認できるもの：

- **現在のバージョン番号**（v0.1.1 からバージョン番号体系を導入：メジャー番号.マイナー番号.リビジョン番号、現在は v0.2.0）。
- **「更新履歴を表示」ボタン**：プログラムのウィンドウ内で各バージョンの更新内容を直接確認。
- **GitHub リポジトリ情報と「GitHub リポジトリへ」ボタン**：ワンクリックで公式リポジトリ <https://github.com/Hatasoft-Studio/Lets-Meow-Toolbox> を開きます。
