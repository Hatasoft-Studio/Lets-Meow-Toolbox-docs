# 機能エリア

プログラム内の機能はやみくもに詰め込まれているのではなく、「リスクの高低、用途の違い」に応じていくつかのエリアに分かれています。このページでは全体像を示し、各エリアの詳しい使い方は対応するリンクからご覧ください。

## 一覧表で全エリアを理解する

| エリア | 位置づけ | 内容 |
| --- | --- | --- |
| 🟢 初心者エリア | デフォルトで無効、リスク確認不要 | Win11 クラシック右クリックメニュー、タスクバー/エクスプローラーの微調整、広告/テレメトリ/通知のおすすめの無効化、安全な UWP アンインストール（ホワイトリスト）、電源/インデックス/自動再生/サムネイルの最適化、ワンクリック復元 |
| 🟡 上級エリア | リスク提示にチェックでロック解除 | Windows Update 一時停止期限/無効化、ワンクリック復元 |
| 📦 プログラムのアンインストール | 独立ページ | Win32 ソフトウェアの一括アンインストール、残留スキャンとクリーンアップ、クリーンアップレポートのエクスポート、「占用解除」と連携 |
| 🔓 占用解除 | 独立ページ | 占用プロセスの検索、プログラムを終了して占用を解放、起動時遅延削除 |
| 🔴 高リスクプラグインエリア | 外部 DLL プラグイン | Defender の無効化 / ファイアウォールの無効化 / Edge・WebView2 の削除。メインプログラム本体には高リスクコードは一切含まれず、`plugins` ディレクトリ内のプラグイン DLL のみを動的に読み込み |
| ⚙️ 設定 | 独立ページ | 外観、構成プリセットのインポート/エクスポート、ログディレクトリ、ワンクリックで全内容を初期化、バージョン情報と更新履歴 |
| 💖 スペシャルサンクス | 独立ページ | 本プロジェクトに統合されたその他のオープンソースプロジェクト |

## なぜこのように分けているのか

- **初心者エリア**の操作は比較的穏やかなため、リスク確認のチェックは不要で、システムをインストールしたばかりの方に最適です。
- **上級エリア**の操作は影響が大きく（Windows Update を触るなど）、リスク提示にチェックしないとロック解除されません。
- **プログラムのアンインストール**と**占用解除**は v0.1.1 から元のエリアから分離され、それぞれ独立したナビゲーション分類と独立ページとなり、使いやすくなりました。
- **高リスクプラグインエリア**は最も特別です：これらの機能（Defender の無効化、Edge の削除など）はリスクが高いため、作者はそれらをすべて**外部プラグイン**にしました。メインプログラム自体には高リスクコードは一行もありません。プラグインを使わなければ、プログラムにはこれらの機能は一切含まれません。

## 全エリアが守るセキュリティの最低ライン

- 全変更・削除・クリーンアップ操作は**すべてユーザーの手動確認が必要**で、自動実行ロジックは一切ありません。
- 残留項目・占用項目は**デフォルトではチェックされておらず**、クリーンアップするには自分でチェックする必要があります。
- 内蔵ブラックリスト：`C:\Windows`、`System32`、`WinSxS` などのシステムコアディレクトリとシステムコアプロセスの強制終了を禁止。
- プログラムはパッキングなし・難読化なしで、内部では Microsoft 純正の Win32 API（RestartManager、MoveFileEx、Registry など）のみを呼び出し、コードはすべてオープンソースで確認可能です。
