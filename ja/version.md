# 更新履歴

バージョン番号体系は v0.1.1 から施行：**メジャー番号.マイナー番号.リビジョン番号**

- メジャー番号：大規模なアーキテクチャ調整 / 破壊的変更時に +1（0.x 段階では全体のリファクタリングを指す）
- マイナー番号：機能追加時に +1
- リビジョン番号：不具合修正 / 最適化時に +1

以下の記録はバージョンの新しい順で、最新が上に来ます。完全なコード変更は各バージョンの **Full Changelog** リンクを参照してください。

## v0.2.0 · 2026-11-06

- 【追加】多言語サポート：外部言語パックの仕組み（`.meowlang`、内容は JSON テキスト）を追加。起動時にプログラムディレクトリの `lang` フォルダを自動スキャンします。
- 【追加】簡体字中国語をソース言語としてプログラム本体に直接組み込み、言語パックをインストールしなくても使用できます。
- 【追加】公式言語パック：繁体字中国語、日本語、英語。プログラムと共に `lang` フォルダ内にリリースされます。
- 【追加】設定ページに「言語を選択」ボタンを追加：独立したウィンドウに `lang` ディレクトリ内のすべての言語パックを一覧表示し、詳細を確認して選択した言語を読み込めます（読み込み後は自動再起動で反映）。
- 【追加】設定ページに「言語パックをインストール」ボタンを追加：`.meowlang` ファイルを選択後、パッケージ名、制作者（公式言語パックは緑色の盾アイコン付き）、適用バージョン、インストール日時、言語タイプ、言語コード、ファイルサイズ、概要、作者サイトを表示します。
- 【追加】インストールフロー：プログレスバー付きのインストールウィンドウ。成功時は「言語パックのインストールに成功しました！」と表示し、失敗時は理由とログパスを表示します。サードパーティ言語パックは再確認が必要です。
- 【追加】同名言語パックの更新/ダウングレード：バージョン番号を自動比較して再確認します。作者または作者サイトが一致しない場合は上書きを拒否し、古い言語パックを手動で削除する必要があります。
- 【追加】言語パックの適用バージョンで `|` 区切りによる複数バージョン番号の指定に対応（例：`0.2.0 | 0.2.1 | 0.2.2`）。
- 【追加】設定ページに「更新を確認」を追加：公式更新インターフェースに最新バージョン番号を要求し、現在のバージョンと自動比較します。新しいバージョンがある場合はバージョン番号、更新内容、「公式サイトで新バージョンを入手」ボタンを表示します。
- 【追加】サポート終了バージョンの検出：更新インターフェースが返すサポート対象外バージョンリストに現在のバージョンが含まれる場合、起動時に強制更新プロンプトを表示し、更新するまで本プログラムを使用できません。
- 【修正】言語管理ウィンドウのリスト項目で、言語パック名が表示されない、選択後にハイライト効果がない問題。

**Full Changelog**：<https://github.com/Hatasoft-Studio/Lets-Meow-Toolbox/compare/v0.1.2...v0.2.0>

<VTDocNote>
公式言語パック（繁体字中国語、日本語、英語）は独立バージョン `v1.1.0-lang` としてもリリースされており、言語パックだけを更新したいユーザーが `.meowlang` ファイルを個別にダウンロードできます。利用ドキュメントは[設定とバージョン情報](/ja/docs/settings.html)、言語パックの形式は[言語パック開発](/ja/dev/language-pack-development.html)をご覧ください。

## v0.1.2 · 2026-10-24

- 【追加】全ページにウェブスタイルの右側スクロールバーを追加：内容がウィンドウを超えると自動的に表示され、スライダーを上下にドラッグ可能、レールをクリックしてページ送り、スライダーのホバー/ドラッグ時にピンク色に変化、角丸の Win11 スタイル。
- 【修正】占用解除ページで、小さいウィンドウ時に占用プロセス一覧の高さが潰れ、ホイールが内部リストに飲み込まれる問題を解消し、ページ全体とともに正常にスクロールできるように。

## v0.1.1 · 2026-10-24

- 【修正】ログシステム：ログをグローバル記録に変更。ユーザーの全設定操作・実行結果・時刻を記録（INFO/WARN/ERROR）。空ファイルではなくなりました。
- 【追加】設定ページに「ワンクリックで全内容を初期化」を追加：全機能設定をデフォルト状態に復元、外観設定のリセット、構成プリセットのクリア。
- 【追加】バージョン番号体系：このバージョンから v0.1.1。バージョン情報ページに現在のバージョンを表示。「更新履歴を表示」ボタンを追加（このウィンドウ内）。
- 【追加】スペシャルサンクス：各オープンソースプロジェクトに「訪問」ボタンを追加し、ワンクリックでプロジェクトホームページ/GitHub リポジトリを開けるように。EZ-Mirror 項目を追加。フォントのぼやけを修正（フォントサイズ拡大、色を濃く）。
- 【追加】画面の再構成：「プログラムのアンインストール」と「占用解除」を初心者エリア/上級エリアから分離し、それぞれ独立したナビゲーション分類と独立ページに。
- 【追加】バージョン情報ページに GitHub リポジトリ情報と「GitHub リポジトリへ」ワンクリックボタンを追加。
- 【修正】二次元モード時のスイッチとボタンの色、文字の可読性を最適化。
