# 更新履歴

バージョン番号体系は v0.1.1 から施行：**メジャー番号.マイナー番号.リビジョン番号**

- メジャー番号：大規模なアーキテクチャ調整 / 破壊的変更時に +1（0.x 段階では全体のリファクタリングを指す）
- マイナー番号：機能追加時に +1
- リビジョン番号：不具合修正 / 最適化時に +1

以下の記録はバージョンの新しい順で、最新が上に来ます。完全なコード変更は各バージョンの **Full Changelog** リンクを参照してください。

## v0.1.2 · 2026-10-24

- 【追加】全ページにウェブスタイルの右側スクロールバーを追加：内容がウィンドウを超えると自動的に表示され、スライダーを上下にドラッグ可能、レールをクリックしてページ送り、スライダーのホバー/ドラッグ時にピンク色に変化、角丸の Win11 スタイル。
- 【修正】占用解除ページで、小さいウィンドウ時に占用プロセス一覧の高さが潰れ、ホイールが内部リストに飲み込まれる問題を解消し、ページ全体とともに正常にスクロールできるように。

**Full Changelog**：<https://github.com/Hatasoft-Studio/Lets-Meow-Toolbox/compare/v.0.1.1...v0.1.2>

<VTDocNote>
このバージョンにはまだインストーラー版（installer-version）が提供されていません。インストーラーとは自包含（self-contained）版のインストールパッケージのことで、しばらくお待ちください。
</VTDocNote>

## v0.1.1 · 2026-10-24

- 【修正】ログシステム：ログをグローバル記録に変更。ユーザーの全設定操作・実行結果・時刻を記録（INFO/WARN/ERROR）。空ファイルではなくなりました。
- 【追加】設定ページに「ワンクリックで全内容を初期化」を追加：全機能設定をデフォルト状態に復元、外観設定のリセット、構成プリセットのクリア。
- 【追加】バージョン番号体系：このバージョンから v0.1.1。バージョン情報ページに現在のバージョンを表示。「更新履歴を表示」ボタンを追加（このウィンドウ内）。
- 【追加】スペシャルサンクス：各オープンソースプロジェクトに「訪問」ボタンを追加し、ワンクリックでプロジェクトホームページ/GitHub リポジトリを開けるように。EZ-Mirror 項目を追加。フォントのぼやけを修正（フォントサイズ拡大、色を濃く）。
- 【追加】画面の再構成：「プログラムのアンインストール」と「占用解除」を初心者エリア/上級エリアから分離し、それぞれ独立したナビゲーション分類と独立ページに。
- 【追加】バージョン情報ページに GitHub リポジトリ情報と「GitHub リポジトリへ」ワンクリックボタンを追加。
- 【修正】二次元モード時のスイッチとボタンの色、文字の可読性を最適化。

**Full Changelog**：<https://github.com/Hatasoft-Studio/Lets-Meow-Toolbox/commits/v.0.1.1>
